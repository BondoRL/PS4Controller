Setup & info

PS-Controller supports Sony DualShock 4 and DualSense controllers on 64-bit Windows.

Installation

Run the small web installer. It downloads the app and installs missing ViGEmBus and HidHide drivers from their official releases. Downloads are checked using SHA-256. The .NET runtime is included in the app download.

Setup needs an internet connection and administrator access. Existing driver services are detected. Restart Windows if requested.

Connect your controller

Connect by USB or pair through Windows Bluetooth settings. For pairing, hold SHARE + PS on a DualShock 4, or Create + PS on a DualSense, until the light bar flashes.

Close other controller mappers such as DS4Windows. Open PS-Controller, select Find controller and start Xbox mode.

Updates

The app can check for updates at startup and every six hours. New versions are downloaded and verified automatically. You choose when to install so your game is not interrupted. Your settings are preserved.

Version 2.3 does not have automatic updates. Install the current version once to enable them.

Help

Open the Diagnostics tab to view the local log. Logs are not uploaded automatically. For help, join the Discord server.

Bluetooth adapters, firmware and games can behave differently. The app and installer do not currently have a publisher signing certificate, so Windows may show an unknown publisher notice.

Source & components

The application source code is private and is not published as open source. You can share the official installer.

Third-party license notices are included in the installation folder. Driver information: HidHide and ViGEmBus. ViGEmBus is no longer actively maintained by its author.
